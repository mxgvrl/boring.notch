## 1. Где живёт

Новая вкладка **Currency** в колонке вкладок слева, после Notes.

- `NotchViews.currency`, иконка SF Symbol `dollarsign.arrow.circlepath` **[?]**
  (варианты: `eurosign.circle`, `banknote`, `arrow.left.arrow.right.circle`).
- Порядок колонки: Home, Shelf, Translator, Ask AI, Notes, **Currency**.
- Тумблер в настройках «Show Currency tab», по умолчанию **включён** **[?]**.

Почему вкладка, а не блок на Home: на Home уже музыка + календарь + камера, места
нет; а ввод с клавиатуры (key-окно, фокус) уже отлажен именно для вкладок.

## 2. Как выглядит

Открытый вырез 640×190, контенту остаётся примерно 560×140 — три поля в ряд помещаются.

```
 Currency                                   ECB · Nov 6  ⟳
 ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
 │ € EUR           │ │ $ USD           │ │ zł PLN          │
 │ 100             │ │ 108.42          │ │ 431.17          │
 └─────────────────┘ └─────────────────┘ └─────────────────┘
 1 EUR = 1.0842 USD   ·   1 EUR = 4.3117 PLN   ·   1 USD = 3.9769 PLN
```

- Верхняя строка: заголовок «Currency» (как «Notes»), справа — источник и дата курса
  и кнопка обновления ⟳ (крутится, пока идёт запрос).
- Три карточки одинаковой ширины, фон `white.opacity(0.07)`, скругление 10 — как у
  редактора Notes. В карточке: подпись валюты (символ + код), под ней число крупно
  (~20 pt, моноширинные цифры).
- Поле, в которое ты сейчас вводишь (источник), подсвечено рамкой/акцентом;
  два других — обычным цветом.
- Нижняя строка — курсы между всеми тремя парами, мелким серым шрифтом **[?]**
  (можно убрать, если лишнее).

## 3. Поведение ввода

- Все три поля редактируемые. Ввёл число в любое → два других пересчитываются сразу,
  на каждое нажатие клавиши.
- Поле, которое ты редактируешь, не переформатируется под тобой; переформатируются
  только два других.
- **Разбор числа** **[?]**: и `,`, и `.` считаются десятичным разделителем
  (`12,5` = `12.5`); пробелы игнорируются (`1 000` = `1000`). Разделитель тысяч
  при вводе — только пробел, потому что `1,000` будет прочитано как 1.0.
- **Вывод результатов** **[?]**: 2 знака после точки, тысячи через пробел:
  `4 311.70`. Для очень малых сумм (< 0.01) — до 4 знаков.
- Очистил поле → два других тоже пустые.
- Ввёл мусор (`12a`) → поле слегка красное, два других остаются пустыми.
- Арифметика в поле (`100+20`, `250*3`) — **не в первой версии** **[?]**.
- Последняя введённая сумма и валюта-источник запоминаются и показываются при
  следующем открытии вкладки (в т.ч. после перезапуска) **[?]**.
- Копирование: обычное выделение + ⌘C в любом поле. Плюс клик по подписи валюты
  (`$ USD`) копирует значение поля без пробелов, подпись на секунду меняется на
  «Copied» **[?]**. Запись в буфер — с `markOwnWrite()`, в историю Shelf не попадает.

## 4. Клавиатура и фокус (как у Translator / Notes)

- Окно выреза может стать key на вкладке Currency; пока поле в фокусе, наведение
  мимо не закрывает вырез (`keepsNotchOpen`).
- ⌃I / ⌃⇧I, приземлившись на Currency, сразу ставят фокус в поле — в **последнее
  поле-источник** (по умолчанию EUR) **[?]**, текст в нём выделен, можно сразу
  печатать поверх.
- Tab / ⇧Tab — переход между полями EUR → USD → PLN.
- Esc — выход из поля (как в Translator), вырез закрывается по обычным правилам.
- Отдельный глобальный хоткей «Open Currency converter» — без значения по
  умолчанию, задаётся в Settings → Shortcuts **[?]**.

## 5. Курсы

- Источник: **Frankfurter API** (референсные курсы ЕЦБ), бесплатно, без ключа:
  `GET https://api.frankfurter.dev/v1/latest?base=EUR&symbols=USD,PLN`.
  ЕЦБ публикует курсы раз в рабочий день около 16:00 CET; в выходные — пятничный.
  Альтернатива **[?]**: **NBP** (Национальный банк Польши, таблица A) — если
  нужны «польские официальные» курсы, например для налогов/бухгалтерии.
- Пересчёт идёт через EUR: USD↔PLN = кросс-курс.
- Кэш в `Defaults` (курсы + дата курса + время запроса); после перезапуска
  конвертер работает сразу, без сети.
- Обновление: при появлении вкладки, если последний запрос был больше 1 часа назад,
  и по кнопке ⟳. Никаких фоновых таймеров, пока вкладка закрыта.
- Нет сети, есть кэш → считаем по кэшу, дата в шапке; если курсу больше 3 дней —
  дата оранжевая.
- Нет сети и нет кэша (самый первый запуск офлайн) → поля неактивны, вместо курсов
  «Rates unavailable · Retry».
